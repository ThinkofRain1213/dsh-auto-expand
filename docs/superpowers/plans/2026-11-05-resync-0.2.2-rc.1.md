# 克隆层重同步到 DSH 0.2.2-rc.1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 15 个克隆文件从基线 `0.2.1-rc.3` 逐行追平到 `0.2.2-rc.1`，让官方新增行为（尤其 `foldedReplies`）在我们接管的渲染路径上正确生效。

**Architecture:** 保持现有文件结构不变，逐文件对照上游 rc.1 源码手工对齐。不重构、不拆分、不改构建配置。现有的自动展开实现（`useAutoDisclosure` / `realign` / 内联高度 `style` / `GroupOpenContext`）原样保留，只把上游新增的分支插进对应位置。

**Tech Stack:** TypeScript 5.9、React 18、tsdown（rolldown）、lightningcss、Cordis 4.1.0、Schemastery 3.19.0、Node 内置 test runner。

**Spec:** `docs/superpowers/specs/2026-11-05-resync-0.2.2-rc.1-design.md`

## Review Focus

- **`foldedReplies` 两种取值**：设 `'all'` 时每条 assistant 回复都留在折叠外，设 `'final'` 时只有最终答案留下。我们克隆的席位必须两种都正确，而不是只认旧的 `answerStep` 判据。
- **用户手动展开后的滚动位置**：`realign()` 是插件自有逻辑，上游新增的 `holding`/`shownCap` 不能把「自动展开后停在底部」这条行为改坏。
- **`capped` 与内联高度并存**：`groupHeight` 消费官方 `capped` 结果；上游把 `capped` 判据从 `open` 换成 `shownCap ?? closingCap` 后，内联高度不能因此跳变。
- **断线重连**：`paused` 状态下计时器必须冻结，但 `holding`（Turn 未关闭而 Session 已停）不能让 status 槽位塌陷。
- **思考内容含 `<signature>`**：`reasoningText()` 剥离后若为空要返回 `null`（整行不渲染），不能留下空白行。

```ts
/**
 * Prepare complete or streaming reasoning for display.
 * @param text - original complete or streaming reasoning.
 * @returns display text, or empty text when no displayable content is available.
 */
function reasoningText(text: string): string {
  if (text[0] !== '<') return text
  const opening = '<signature>'
  if (opening.startsWith(text)) return ''
  if (!text.startsWith(opening)) return text
  const closing = '</signature>'
  const end = text.indexOf(closing, opening.length)
  if (end === -1) return ''
  let start = end + closing.length
  while (start < text.length) {
    if (text[start] === '\n') start++
    else if (text[start] === '\r' && text[start + 1] === '\n') start += 2
    else break
  }
  return text.slice(start)
}
```
